## 三、契约测试设计要点

- **单源复用**：防漂移用例经 importlib 加载 `scripts/export_openapi.py` 的
  `generate()`，与 CI `--check` 同一实现——不重写序列化（X-06 双实现教训）；
- **CRLF 归一**：Windows autocrlf checkout 场景与导出脚本同款处理，避免本地假阳性；
- **不重复断言**：运行时 422 形态已由 `tests/test_validation_handlers.py` 覆盖
  （P-01~P-04），契约测试只守文档本身（tags/securitySchemes/计数/唯一性）；
- **计数即哨兵**：16/17 硬断言是刻意设计——API 面任何增删都会逼评审者显式更新
  本文件与四族清单，防契约悄悄漂移。
