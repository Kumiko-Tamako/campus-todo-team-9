## 二、设计要点

1. **CRLF 归一化**：Windows `core.autocrlf` checkout 出 CRLF 文件，`--check` 比对前 `replace("\r\n", "\n")`——本地与 CI（ubuntu LF）行为统一，消除假阳性
2. **`newline="\n"` 显式写盘**：防 Windows 默认 CRLF 使每次重导出 git diff 全文件翻动
3. **schema 外全局错误码**：实测 responses 只声明 200/201/204/422；401/400/413/405 来自依赖层/中间件，不在 schema——契约说明以速查表承载，前端类型生成时不可见但必须处理
4. **依赖升级触发 `--check` 红**：FastAPI/Pydantic 版本变化会改变 schema 结构——特性（提醒重新导出），非缺陷
