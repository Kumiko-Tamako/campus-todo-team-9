## 一、功能概述

登录失败计数与锁定（US-L04）：Redis 计数器 `login:fail:{identifier}`，**滑动窗口**——
每次失败 INCR + EXPIRE(900s) 组 MULTI/EXEC 原子执行（消除"INCR 成功、EXPIRE 未达"的永不过期误锁窗口），
失败达 **5 次**后第 6 次起返回 **423 Locked**（detail="尝试次数过多，账号临时锁定，请稍后再试"），
**登录成功即 DEL 清零**；窗口 15 分钟内持续失败会刷新 TTL。

**口径（裁定 D4/D5）**：对**全部 identifier 统一计数**——不存在的账号同样累计与锁定（与 401 同一防枚举口径，
不泄露账号存在性；代价=可被恶意锁号，Could 级故事接受，已写进契约说明）。
**设计边界**：锁定是瞬态运维状态、非领域不变式（aggregates.md User 不变式未列它）——**不动 User 聚合、无迁移**，
domain 层零改动。

## 五、行为口径表（对前端契约）

| 场景 | 行为 |
|:--|:--|
| 第 1–5 次失败 | 401（InvalidCredentials 统一消息，持续累计计数） |
| 第 6 次起（窗口内） | **423**（含正确密码——锁定先于凭证校验） |
| 窗口滑动 | 每次失败刷新 TTL（15min），持续攻击不解除 |
| 成功登录 | 计数清零（后续失败重新从 1 累计） |
| 窗口过期 | 自动解锁（键 TTL 到期） |
| 幽灵账号（未注册） | 同样计数、同样锁定（防枚举口径） |
